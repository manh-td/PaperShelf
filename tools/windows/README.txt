PaperShelf for Windows (x64)
============================

Run:  PaperShelf.exe
Keep the whole folder together; PaperShelf.exe needs the folders next to it:
  helper\               the PDF engine (Java)
  runtime\              a Java 17 runtime used only by PaperShelf (no system Java needed)

Your library (papers, analysis cache, reading positions, settings) is stored in
  %APPDATA%\PaperShelf
Back up that folder to keep your library. Deleting this app folder does not touch it.

Windows may warn that the app is from an unknown publisher (it is not code-signed):
choose "More info" and "Run anyway".

Keys in the library: Enter open, Delete trash, F2 rename, Ctrl+O import PDFs,
Ctrl+Shift+O import a folder, Ctrl+F search, Ctrl+N new collection, F11 fullscreen.
Keys in the reader: Right/Space next, Left back, PageDown/PageUp page, Ctrl+1-4 mode,
Ctrl+=/- zoom, Tab contents, Ctrl+, settings, Ctrl+Down/Up next/previous comment,
Ctrl+M minimize/expand comments, Ctrl+R put the comments together into a review,
Esc back to the library. To comment on the highlighted sentence, just start typing
(in Free mode, drag across text first): Enter adds a point, Tab picks a category,
Ctrl+Enter saves, Esc discards.
